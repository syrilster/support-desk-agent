## Extended return period

Customers may return eligible items within **60 days of delivery** under the Extended Returns Program.

The 60-day period begins on the date the carrier records delivery. Customers requesting a return should provide the order information needed to confirm the delivery date.

## Eligibility

Eligible items may be returned for either **store credit or a refund**, subject to the return process and review.

The program is intended to provide customers with additional time to decide whether an eligible purchase is right for them. Customers should initiate the return request within the applicable 60-day period.

## Return condition

Items should be returned in resalable condition and with the relevant order information. Support may request details about the condition of the item before providing return instructions.

Final-sale, hygiene, electronics, or other specially handled items may be subject to the applicable rules governing those products.

## Examples

An eligible item delivered on **August 20, 2026** falls within the 60-day period on **October 7, 2026**. A customer asking to return such an item should have the delivery date and item eligibility checked before the return is processed.

Store credit and refunds are both available for eligible returns under this program, with refund processing handled according to the applicable refund procedure.
