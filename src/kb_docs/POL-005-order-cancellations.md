## Standard cancellation

Customers may cancel an order **free of charge while its status is "processing"**. Once an order has shipped, cancellation is not available; customers should use the Returns Policy where a return is eligible.

Support should check the current order status before confirming that a cancellation can be made.

## Custom and personalized orders

Orders containing **custom or personalized items cannot be cancelled after 24 hours** from the time the order was placed. This restriction applies even if the order status still appears to be processing.

Within the first 24 hours, a cancellation request for a custom or personalized item may be considered under the normal cancellation process.

## Refunds

When a cancellation is successfully completed and a refund is approved, the refund is processed according to the applicable refund timeline. Cancellation approval and refund completion are therefore separate events.

A cancelled order with a refund already approved should not be treated as an order that still needs to be cancelled. Instead, Support should explain the refund status and expected timing if the customer is asking when the money will arrive.

For any order already marked shipped, Support should not promise cancellation and should instead explain the available return process.
