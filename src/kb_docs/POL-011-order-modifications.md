## Address changes

A shipping address can be changed only while an order has the status **"processing"**.

There is one important operational exception: an address change is **not possible once a shipping label has been created**, even when the order status still displays "processing."

Support must therefore check both the displayed order status and whether a shipping label has already been created.

## What to do

If an order is processing and no label has been created, Support may handle an eligible address-change request under the normal modification process.

If a label has already been created, do not promise that the address can be changed merely because the order still says processing.

Once an order has shipped, an address modification is not available through this policy. Customers should contact Support if they need help understanding the shipment or available return options.

The label-creation rule is intentionally stricter than the status-only rule. The presence of a created label takes priority for address changes.

Customers should provide the new address carefully. Support should confirm whether the change is technically available before telling the customer that it has been made.
